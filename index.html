Introdução ao JavaScript

O que é o JavaScript?

É uma linguagem de programação utilizada para criar aplicações interativas e sistemas de software.

Ele é responsável por:

  • Repsonder apliques
  • Validar formlários
  • Atualizar conteúdos
  • Buscar dados de APIs
  • Controlar o comportamento de aplicação

IMPORTANTE:JavaScript não é Java. Apesar da semelhança nos nomes, são linguagens totalmente diferentes, com caracteristicas e ecossistemas próprios.

Curiosidade: Foi criado em apçenas 10 dias.

O que mais da para fazer com JavaScript?

  • FrontEnd
    • Criar interfaces interativas
    • Menus
    • Validações
    • Filtros
    • Animações
    • Dashboards
    • Aplicações com React, Vue, Angular, Astro e etc.
  • BackEnd
    • NodeJs
    • Criar APIs REST
    • Autenticação
    • Processar requisições
    • Integrar com serviços e com banco de dados
  • Mobile/Desktop
    • Criar aplicativos
    • React Native e Electron
